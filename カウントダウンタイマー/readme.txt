💡 このツールについて
「Countdown Timer」は、プレゼンテーション、会議、学習、作業などの時間管理をスタイリッシュかつ高機能にサポートする、単一HTMLファイル完結型のWebカウントダウンタイマーです。 
🌟 主な特徴
🎨 視覚的に直感的なデザイン
・ 残り時間を円形プログレスバー（リング）と大画面テキストでリアルタイム表示。残り時間に応じてリングの色が変化します（青 ➔ 黄 ➔ 赤）。 
・ 予鈴やタイムアップ時には背景が点滅し、音だけでなく視覚的にも確実にお知らせします。 
🎵 豊富なWeb Audio音源（全15種類・外部ファイル不要）
・ ブラウザの「Web Audio API」を活用して音を自動生成するため、音声ファイルのダウンロードや読み込み遅延がありません。 
⏱️ バックグラウンドでもズレない高精度設計
・ 端末の絶対時間を基準に計算しているため、別タブに切り替えたり画面をバックグラウンドに回したりしてもタイマーの時間がズレません。 
📱 スマホ・全画面表示・スリープ防止に対応
・ フルスクリーン表示モード搭載。スマートフォンでも最適化されたレイアウトで動作し、計測中は画面のスリープ（消灯）を自動防止します。 
💾 設定の自動保存（ローカルストレージ）
・ 最後に設定した時間、アラーム音、予鈴などのオプションはブラウザに自動保存され、次回起動時もそのまま利用できます。 

画面構成と機能仕様
1.📺 メイン画面（タイマー表示エリア）

項目			内容・仕様
円形プログレスバー	残り時間の割合を円状のメーターで表示。 
			残り30%以上：水色
			残り30%以下：黄色
			残り10%以下：赤色

デジタル時間表示	時間を 00:00:00 形式（または 00:00）で中央に大きく表示。 

ステータス表示		予鈴発動時（予鈴 ○秒前）やタイムアップ時（Finished）にメッセージを表示。 

⛶ 全画面ボタン		画面右上にあるボタンでブラウザのフルスクリーン表示を切り替え。 

ショートカット案内	画面右下にキーボード操作のガイドを薄く表示。 


2.⚙ 設定ドロワー（画面下部コントロールパネル）
画面下部にカーソルを近づけるか、▲ SETTINGS ▲ のハンドルをクリック／ホバーすることでスライドオープンします。 

🟢 アクションボタン
▶ スタート (Enter)：カウントダウンを開始します。 
⏸ 停止 / 再開 (Space)：一時停止・再開を切り替えます。一時停止中はボタンが点滅してお知らせします。 
↺ リセット (Esc)：タイマーを初期時間に戻します。 

⏱ 時間設定
・プリセット選択：10分 15分 20分 30分 40分 45分 50分 60分 カスタム からワンタップで選択。 
・手動設定 (時 : 分 : 秒)：スピンボタン（▲/▼）または直接数値入力。▲/▼ボタンは長押しで連続変更可能。 
・↺ ゼロクリアボタン：時間をすぐに 00:00:00 にリセット。 

🔔 アラーム・予鈴オプション
・アラーム音選択：全15種類から選択可能。♪ 再生 ボタンで3秒間のテスト試聴が可能です。 
・予鈴（プレアラーム）：
    残り時間割合（例：残り 20%）を指定して事前にお知らせ。 
    予鈴時には予告音とともに背景が黄色く3秒間点滅します。 
    選択中のパーセンテージに応じた発動時間がリアルタイム表示されます（例: @ 03:00）。 
・アラーム鳴動時間：タイムアップ時のアラーム鳴動秒数を設定（1〜999秒、デフォルト10秒）。 
・ループ再生：ONにすると、タイムアップ後に自動でタイマーが最初からリスタートします。 
・設定を初期化：保存された全設定をクリアし、初期状態でリロードします。 

⚠ ライブアップデート機能
タイマー稼働中に設定を変更すると、誤動作を防ぐため [⚠設定を変更しました。ここを押して反映] という警告ボタンが表示され、確認ダイアログを経て安全に設定を反映できます。 

🎵 搭載アラーム音一覧（全15種類）
1.グランドピアノ (Chord) - 華やかな和音の響き 
2.学校のチャイム (Westminster) - おなじみのウエストミンスターの鐘 
3.トライアングル (Triangle) - 高く澄んだ金属音 
4.天使のハープ (Harp) - アルペジオの美しい和音 
5.ウィンドチャイム (Wind) - ランダムに響く爽やかな鈴音 
6.瞑想のボウル (Singing Bowl) - 落ち着いたうねりのある倍音 
7.オーケストラ (Strings) - 豊かなストリングス和音 
8.マリンバ (Marimba) - 木琴の温かいポンポン音 
9.クリスタルベル (Synth Bell) - 透明感のある高音チャイム 
10.シンプルチャイム (Ding-Dong) - 2音のシンプルな呼び出し音 
11.銅鑼 (Gong) - 重厚でインパクトのある響き 
12.オルゴール (Music Box) - 優しくノスタルジックな音色 
13.教会の鐘 (Church Bell) - 厳かな重低音ベル 
14.勝利のファンファーレ (Trumpet) - 明るくテンポの良いトランペット風 
15.決定音 (Level Up) - ピコピコゲーム風のレベルアップ音
