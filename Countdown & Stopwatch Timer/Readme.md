💡 このツールについて
「Countdown & Stopwatch Timer」は、プレゼンテーション、会議、講演、授業、行事進行、スポーツ計測や日々の作業まで幅広くサポートする、単一HTMLファイル完結型の多機能タイマーWebアプリです。
カウントダウン／ストップウォッチ／時間指定アラームの基本機能に加え、ラップ記録の出力、マイプリセットでの設定保存と呼び出し、発表や講演でも活用できる連続タイマー機能などを1つにまとめています。

🌟 主な特徴
⏱️ カウントダウン・ストップウォッチ・アラームの3モード搭載
・ カウントダウン（残り時間指定・終了時刻指定・予鈴・超過計測・ループ再生）に加え、ミリ秒単位のストップウォッチや、繰り返し・スヌーズ対応の時間指定アラームを切り替えられます。
🔁 発表や講演に便利な「連続タイマー（シーケンス）」機能
・ 「ステージ準備 → 発表本番 → 質疑・転換」などの複数ステップを順番に自動連続実行でき、発表・講演やイベント進行の時間管理をスムーズに行えます。
📌 設定を保存・呼び出せる「マイプリセット」＆ JSON入出力
・ よく使う時間・タイトル・予鈴・音色などの設定をマイプリセットとして保存・ワンクリック呼び出しが可能。JSON形式での書き出し・読み込みにも対応しています。
🏁 ラップ記録と多彩な出力機能（コピー・CSV／TXT保存）
・ ストップウォッチやカウントダウンのラップを記録でき、累計／区間表示切替、BEST／WORST表示、メモ入力に加え、クリップボードコピーやCSV／TXTファイル出力に対応しています。
🎨 視覚的に直感的なデザイン＆「投影」モード
・ 円形プログレスゲージと大きく見やすい時間表示で残り時間や経過時間を把握でき、予鈴・終了・アラーム時は音と視覚通知でお知らせします。会場スクリーン向けのシンプルな「投影」モードも搭載しています。
🎵 豊富なWeb Audio音源（全15種類・外部ファイル不要）
・ ブラウザの「Web Audio API」で音を自動生成するため、外部音声ファイルの用意や読み込み遅延なしで鳴動・試聴が可能です。
⏱️ バックグラウンドでもズレない高精度設計
・ 端末の時刻・経過時間基準で計算するため、別タブ切替やバックグラウンド遷移時も計測がズレにくく、画面スリープ防止（対応ブラウザ）やブラウザ内自動保存（localStorage）にも対応しています。

画面構成と機能仕様
1. 📺 メイン画面・モード切替・ラップパネル

項目                  内容・仕様
モード切替タブ        「カウントダウン」「ストップウォッチ」「アラーム」を切り替え（ラップ表示は計測モード時に利用可能）。
タイトル＆時計        画面上部でタイトル入力（自動保存）ができ、右上には「投影」切替、消音／音量、テーマ切替、全画面、現在日時・時刻を表示。
円形ゲージ＆時間表示  残り時間や経過時間を円形ゲージと分割時間表示（時・分・秒・ミリ秒）で大きく表示。カウントダウン中はクイック時間調整（-5分〜+5分）にも対応。
ラップ記録パネル      累計／区間メイン表示の切替、区間合計・平均・件数サマリー、BEST／WORST表示、個別削除、メモ入力、コピーおよびCSV／TXT保存に対応。

2. ⚙ 設定ドロワー・拡張機能

項目                  内容・仕様
カウントダウン設定    プリセット選択、スピナー／テンキー入力、終了時刻指定、予鈴（割合または残り時間）、本鈴鳴動時間（1〜999秒）、ループ再生、超過時間計測（+MM:SS）に対応。
ストップウォッチ設定  経過時間到達時または一定間隔ごとの警告音設定に対応。
時間指定アラーム      時刻（HH:MM:SS）・ラベル・繰り返し（1回のみ／毎日／平日）・音色・スヌーズ分数を登録でき、鳴動時はスヌーズまたは停止を選択可能。
マイプリセット        現在の時間・タイトル・予鈴・本鈴・鳴動時間・ループ・超過計測などの設定を名前付きで保存・呼び出し・削除可能。
連続タイマー          複数ステップ（名称・時間・予鈴・音色）を構成して順次自動実行。テンプレートやステップ追加・並べ替え・全体ループに対応。
JSON入出力・表示      マイプリセットと連続タイマー構成をJSONで確認・コピー・ファイル入出力でき、バックアップや端末間共有に活用可能。
ライブアップデート    計測中や一時停止中に設定を変更した際、確認を経て安全に反映できる仕組みを搭載。

⌨  キーボードショートカット
キー                  動作
[Enter]               未開始時はスタート、計測中／一時停止時はラップ記録（投影モード中は未開始／一時停止時にスタート）
[Space]               一時停止 / 再開の切替（アラーム鳴動中モーダル表示時は停止）
[L]                   ラップタイムの記録
[Esc]                 入力欄フォーカス解除 → 投影モード解除 → 設定ドロワー閉じる → アラーム停止／リセット
