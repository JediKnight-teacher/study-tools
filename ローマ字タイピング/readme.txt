💡 このツールについて

◆楽しく習得
	小学校低学年から、遊び感覚でローマ字入力を覚えられます。
	タイムアタックやランキング表示などのゲーム要素を取り入れ、楽しく継続できるように設計しました。

◆学校の端末に対応
	GIGAスクール構想の端末（Windows / Chromebook）のブラウザで動作します。

◆ネット不要
	このHTMLファイルをダウンロードすれば、インターネットがない環境でも家庭や学校で遊べます。

◆ユニコード絵文字とシンプル・互換性
	イラストやアイコンは画像素材を使わず、Unicode絵文字のみを使用しているため動作が軽く、
	異なるデバイスやOS間でも高い互換性があり、ファイルの破損も起きにくい設計です。

注意点
	本ツールはタイピング練習用のため、物理キーボードでの操作を前提としています。
	画面上のキーボード（ソフトウェアキーボード）には対応していません。
