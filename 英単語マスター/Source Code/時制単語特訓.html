🏫 目指せ！時制マスター
「現在形」「過去形」「未来形」を自由に使いこなすためのトレーニングだよ。
頭で考える前に、口からスッと英語が出てくるように練習しよう！

⚙️ コースと設定

  • 10〜30問コース: 休み時間やスキマ時間にサクッと練習！
  • 全50問チャレンジ: テスト前の力試しに。全問正解を目指そう。
  • 音声 (🔊): ONにすると正解した時に英語を読み上げるよ。
    「現在→未来→過去」のリズムを耳で覚えよう。
  • 全画面 (⛶): 集中したい時にオススメ。

🎮 操作方法

  • 答え方: 画面の日本語を見て、指示された時制（過去形など）を入力してね。
  • 困った時は: 「💡 ヒント」ボタンを押すと、少しずつ答えが見えるよ。
  • PCなら: Enterキーで「決定」や「次の問題」に進めるので便利！
⚠️ 注意事項
・音声が出るので、周りの迷惑にならないように音量に注意してね。
・ブラウザの設定によっては音が出ないことがあります。

  • 🧠 本ツールは、単なる単語帳ではありません。知識として知っているはずの「現在形・過去形・未来形」を、思考を介さず反射的に出力するための神経回路トレーニングです。
