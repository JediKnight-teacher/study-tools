💡 このツールについて
「English Speech & Pronunciation Trainer」は、Web Speech API（音声合成・音声認識）を活用し、ブラウザ上で効果的な英語の発音練習やスピーチトレーニングを行えるWebアプリケーションです。

⚙️ システム概要
🖥️ 対応環境:
  Google Chrome / Microsoft Edge（Chromebook・Windows PC・モバイル対応）
  ※マイク許可およびHTTPS環境（またはlocalhost / ローカルファイル）が必要です。

🛠️ 使用技術:
  Web Speech API（音声合成 SpeechSynthesis / 連続音声認識 SpeechRecognition）、Web Audio API（マイク録音・Canvas波形描画）

✨ 主な機能
🗣️ お手本音声再生
  速度・高さの自由な調整や、強調単語（アクセント）のハイライト表示に対応。
🎤 発音・スピーチ判定 & 波形
  マイク入力による一致度スコア判定。一致/ミス単語の比較分析や、発話の強弱・間合いが確認できるマイク波形表示。
🔥 通し稽古モード
  台本全体を止まらずに連続録音。「自分のペースで進める」の設定に応じてキー操作送り（→キー）と自動送りを自在に切替可能。
🔄 A/B 聞き比べ
  お手本音声と自分の録音音声をその場でワンタップで聞き比べ。
📝 台本インポート・編集
  英文・和文の直接作成や、JSON形式ファイル（.json）の保存・読み込み機能。

⚙️ 詳細設定の使い方
🔊 音声・再生設定:
  お気に入りのスピーカー音声を選択したり、声の高さ（ピッチ）や再生スピードを変更できます。「アクセント強調」をONにすると重要な単語がハイライトされ、ゆっくり・高く強調して再生されます。
🎤 判定・タイミング設定:
  判定の厳しさを1〜5段階で変更できます。「沈黙の待ち時間」は話し終わってから判定に移るまでの秒数を設定します。「自分のペースで進める」をONにすると、自動で進まず手動で自分のリズムで練習できます。
📱 表示・分析設定:
  和訳の表示/非表示を切り替えたり、「単語チェック」をONにして発音の正誤（一致・ミス・余分な単語）を視覚的に確かめることができます。

⌨️ ショートカット操作
  Space : 音声再生・通し稽古の一時停止 / 再開
  → : 次のセリフへ進む（通し稽古時）
  Enter : 判定結果ダイアログを閉じる
  Esc : モーダルを閉じる / 練習・再生の中断
